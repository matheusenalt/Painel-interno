# Branding opcional

A edição pública não inclui logotipo, background ou qualquer identidade visual real.

Para testar branding em laboratório, você pode adicionar **localmente**:

- `logo.svg` — logotipo principal;
- `logo-light.png` — variação opcional para fundo claro;
- `logo-dark.png` — variação opcional para fundo escuro;
- `background.png` — background opcional do Nextcloud.

Os scripts verificam a existência desses arquivos antes de tentar aplicá-los.

Não publique marcas, logos ou materiais que você não tenha autorização para distribuir.
